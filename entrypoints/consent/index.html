Before Type Right sends your text anywhere

Type Right checks what you type with two engines:

  • LanguageTool checks spelling and grammar. Your text is sent to the LanguageTool server set in Settings (the free public API by default).
  • GLM (Zhipu AI / Z.ai, a provider in China) checks for unnatural wording and grammar LanguageTool misses. Each finished sentence you type is sent to Z.ai's API with your API key.

Nothing is sent to GLM unless you accept below. You can list sites that must never be sent to GLM in Settings, and withdraw consent there at any time.
